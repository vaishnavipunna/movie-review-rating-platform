# Movie Review & Rating Platform

## Project Description
A web-based platform where users can browse movies, submit reviews, and rate movies. The system stores reviews and ratings and displays them dynamically.

## Features
- View movie details
- Submit reviews
- Rate movies
- Store user feedback
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
movie-review-rating-platform/
├── frontend/
└── README.md

## How to Run
1. Clone the repository
2. Open frontend in browser
